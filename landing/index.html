003 Privacy

Two modes. You choose who reads the prompt.

Standard

Any OpenAI client. The relay reads the prompt in transit, never stores it.

Private

NEAR AI's SDK encrypts on your machine. The relay forwards ciphertext.

  • Both: attested TEE models only
  • Both: debited per call on NEAR
  • Private: the SDK verifies the model's signature
  • Private: hides content, not metadata

// NEAR AI's SDK, pinned at nearai/inference-sdk@a0bf5fd (E2EE v3, PR #127).
import { InferenceClient, verifyDeploymentImageProvenance } from '@nearai/inference-sdk';

// "Verified" must mean NEAR's own gateway images, not just genuine TEE hardware.
const build = (repository, workflow = '.github/workflows/build.yml') => ({ repository, workflow });
const GATEWAY_IMAGES = {
  'nearaidev/cloud-api': build('nearai/cloud-api'),
  'nearaidev/cvm-ingress': build('nearai/cvm-ingress', '.github/workflows/build-push.yml'),
};

const client = new InferenceClient({
  baseUrl: 'https://api.infernear.dev/v1',
  apiKey: process.env.INFERNEAR_API_KEY, // inf_…
  e2ee: true, // encrypt to the model's TEE key, here, before sending
  gatewayVerification: {
    verifiers: {
      deployment: ({ appCompose }) =>
        verifyDeploymentImageProvenance({ appCompose, imagePolicies: GATEWAY_IMAGES }),
    },
  },
});

const completion = await client.chat.completions.create({
  model: 'Qwen/Qwen3.8-27B',
  messages: [{ role: 'user', content: 'Reply with the word ok.' }],
  max_tokens: 256,
});

// Check the model's signature over the exact request and reply bytes.
const receipt = await client.verifyResponse(completion.id);
console.log(`Verified ${receipt.signatureKind} reply:`, completion.choices[0].message.content);

Known limits

Private mode verified live once

A 2026-11-12 probe: JS and Python, plain and streaming. Signatures verified; charges matched NEAR's bill. Details

Standard mode: the relay reads content

The relay and the Cloudflare Tunnel in front of it see standard-mode prompts and replies in transit.

Encryption hides content, not metadata

Request size, timing and token counts stay visible to the relay.

Model build check is off

TEE attestation and signatures are still verified. NEAR's proxy-build check rejects NEAR's own deploys.

Relay trusted for prices and attribution

It cannot spend principal. Both are recomputable from chain data.

Deposits carry strategy risk

Losses fall on depositors pro-rata, with no reserve. Each vault is capped at about $10K.
